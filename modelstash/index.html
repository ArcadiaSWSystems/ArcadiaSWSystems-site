ModelStash

Your models, kept. A self-hosted hub for the AI models your network already uses: pull them once from Hugging Face, Ollama and more, keep each model's card, licence and samples even after upstream deletes them, and serve them to every tool you run. Nothing downloads the same 40 GB twice.

A look inside

Know what you have, and what it needs.

These are real screens from a ModelStash test hub, holding public models from Hugging Face and Ollama's library. Nothing is mocked up. They show all three looks; see below for which come with which licence.

Three looks

Browse it like a feed, a gallery, or a paper.

Each person picks their own look, in light or dark. Gallery comes with every hub; Darkroom and Index come with a business licence. Whichever you use, your hub's activity reads like a feed, and a proper table is always there when you need one.

Works with your tools

Point your tools at the hub. That's it.

ModelStash speaks Hugging Face's API and is an Ollama registry, so transformers, diffusers, vLLM and Ollama fetch from your hub instead of the internet. Ask for a model it doesn't hold yet, and the pull-through cache fetches it once, streams it to everyone asking, and keeps it.

# Any tool built on huggingface_hub eval "$(mstash env)" python -c "from transformers import AutoModel; \ AutoModel.from_pretrained('Qwen/Qwen3-0.6B')" # The Hugging Face CLI HF_ENDPOINT=http://hub.lan:8642 \ hf download openai/whisper-tiny # Ollama, from your hub ollama pull --insecure hub.lan:8642/library/llama3.2:3b

On your phone

Your stash, in your pocket.

The web app works on any screen on your network, phone included. There's nothing to install on your devices.

What it does

One copy of every model.
Every tool served.

Pull from anywhere Hugging Face, CivitAI, Ollama's library, ModelScope, GitHub Releases or any address, with your tokens set once for the whole hub.
Keeps what upstream forgets Each model's card, licence and sample pictures with their settings. It tells you when upstream removes, updates or relicenses something you hold.
Serves every tool A Hugging Face-compatible API, an Ollama registry, plain resumable downloads and the mstash command line.
Checked, not just stored Every file is checked against its published hash, and risky file types are flagged before anyone uses them.
Know before you run What each quant needs in GPU memory, dataset previews, add-ons, and ComfyUI workflows with the files they load.
Stays yours Readable folders on the disks you choose, a NAS included. Sign-in by default, no telemetry, and it works air-gapped.
Ready for a business With a business licence: groups, storage quotas, pull approval, a licence policy with its report, an audit log viewer, and sign-in with OpenID Connect, SAML or LDAP.
Installs in a minute One script for macOS, Linux or Windows with no admin rights needed, or a Docker container.
